PRIYA SURPRISE WEBSITE
======================

Open index.html in a modern browser to preview the website.

Project structure:
- index.html: page content
- css/style.css: styling and animations
- js/script.js: navigation and interactions
- assets/: optional photos, music, and icons

No build step, Node.js, or dependencies are required.

Before sharing:
- Confirm the March 2026 friendship date is accurate.
- Personalize any wording you want.
- Test the website on a phone-sized browser.

For free hosting, you can upload the folder to a static hosting provider such as GitHub Pages or Netlify.
